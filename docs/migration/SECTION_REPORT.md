## 可执行区间（签名扫描的范围）

客户端的 `CodeSection::find` 只扫描 `IMAGE_SCN_MEM_EXECUTE` 的节。镜像里有 3 个：

- `(未命名)` 0x1000 .. 0x8b6f8a9（0x8b6e8a9）
- `.winlice` 0xc0d5000 .. 0xcf7b000（0xea6000）
- `.boot` 0xcf7b000 .. 0xd7aa000（0x82f000）

离线扫描器使用同一规则，因此 43 项失败清单与线上逐名一致（见 TEST_REPORT）。

## 与迁移直接相关的三条结论

1. `.text` 在两个样本间**逐字节相同**（0x8B6E8A9 字节），代码级分析可以互相印证。
2. `.rdata` 有 2059/7454 页不同，差异是指针值；**vtable / COL / RTTI 只能读镜像**。
3. 镜像里 `.winlice` 为 0 字节（未转储），任何“已覆盖全部代码”的结论都不成立。
